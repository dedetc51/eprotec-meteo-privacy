# Politique de confidentialité — Météo DPS pour eProtec

Ce dépôt contient la page publique de politique de confidentialité destinée aux fiches de publication Microsoft Edge Add-ons, Chrome Web Store et Safari/App Store.

## Publication avec GitHub Pages

1. Le dépôt doit être **public** pour que la page soit accessible simplement à tous les testeurs et aux stores.
2. Ouvrir **Settings > Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Choisir la branche `main` et le dossier `/ (root)`, puis **Save**.
5. Après quelques instants, la page sera disponible à :
   `https://dedetc51.github.io/eprotec-meteo-privacy/`

Utiliser cette URL dans le champ « URL de la politique de confidentialité » des stores.
